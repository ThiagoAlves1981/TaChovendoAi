Sobre o Tá Chovendo Aí?

Uma solução moderna de consulta meteorológica em tempo real, focada em performance, design responsivo e segurança de dados.

A Ideia

Transformar a consulta meteorológica em uma experiência simples e rápida. Acompanhe a previsão de qualquer cidade com dados precisos e atualizados instantaneamente.

Segurança & Proxy

Utiliza uma arquitetura Client-Server com um backend Node.js atuando como Proxy. Isso garante que as chaves de API permaneçam 100% protegidas e ocultas no servidor.

Deploy & CI/CD

Hospedado no GitHub Pages com pipeline de deploy automático via GitHub Actions e backend dinâmico rodando em nuvem no Render.com.

Tecnologias Utilizadas
HTML5 & CSS3 Bootstrap 5 JavaScript (ES6+) Node.js & Express API Proxy GitHub Actions Render.com
